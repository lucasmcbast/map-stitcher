# Map Stitcher

Browser-App zum Zusammensetzen überlappender Karten-Screenshots.

- Bilder bleiben lokal im Browser.
- Gleiche Zoomstufe verwenden.
- Ideal: 20–40 % Überlappung.
- GitHub Pages kompatibel.

Die App nutzt OpenCV.js für Template Matching. Sie ist für flache Karten-Screenshots optimiert, bei denen benachbarte Bilder reine Verschiebungen derselben Karte darstellen.
